# Java Homework Projects

Homework assignments and exercises from the Java Basics course, covering fundamental Java programming concepts.

## Topics Covered

| # | Topic | Description |
|---|-------|-------------|
| 1 | Intro to Java | Java setup, IDE configuration, first programs |
| 2 | Java Syntax | Variables, data types, operators, expressions |
| 3 | Loops, Methods, Classes | Control flow, method definitions, class basics |
| 4 | Java Collections Basics | Arrays, ArrayList, basic data structures |

## Project Structure

```
java-homework-projects/
├── Intro-Java-Homework/
├── Java-Syntax-Homework/
├── Loops-Methods-Classes-Homework/
└── Java-Collections-Basics-Homework/
```

## How to Run

### Using Eclipse/IntelliJ
1. Import the project folder as an existing project
2. Navigate to the desired class with a `main` method
3. Right-click and select "Run"

### Using Command Line
```bash
cd <homework-folder>/src
javac *.java
java <ClassName>
```

> **Note:** These are course homeworks from Software University (SoftUni). They are intended for educational purposes and demonstrate fundamental Java programming concepts.
